Independent Windows C# and POSIX Node fixtures expand native initialization paths once, then verify restart skips initialization and preserves custom peer JSON. The two new POSIX cases failed against the original launchers with misplaced peer JSON; all 12 launcher/path integration cases passed after repair (Vitest 2.81 seconds with one worker). TypeScript and formatting checks passed. The native matrix now also runs the path integration suite on macOS; Windows runs its expanded-handoff PowerShell case. The app version and README downloads identify v0.1.3. Hosted results and publication are recorded after completion.
